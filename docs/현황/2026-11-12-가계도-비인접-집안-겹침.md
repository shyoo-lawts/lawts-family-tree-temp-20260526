# 가계도 아래 세대 겹침 수리

- 제보: 첨부 PDF에서 중간 인원이 보이지 않음. 이용 경로는 GitHub Pages 프로토타입.
- 재현: 아래 세대가 3명 / 0명 / 3명인 부모 세 명을 나란히 배치하면, 첫 집안 마지막 사람과 다음 집안 첫 사람이 같은 좌표에 놓인다.
- 원인: `extraGap`이 바로 옆 부모 두 명만 비교하므로 자녀 없는 부모 너머의 집안을 보지 못한다.
- 수정: 기존 간격을 유지하면서, 앞서 배치한 아래 세대의 오른쪽 끝과 충돌할 때만 다음 부모를 이동한다. 폭 계산과 실제 배치는 `rowOffsets`를 공유한다.
- 검증: 수정 전 조카→질손 / 자녀→손자녀 재현 테스트 모두 실패, 수정 후 모두 통과. 기존 내장 샘플 3종의 좌표는 라이브 원본과 동일.
- 첨부 원본 데이터는 변경하지 않았다. 수정 출력은 17명 전원 표시·상자 겹침 0건이며 PDF를 렌더링하여 육안 확인했다. 고객 자료는 저장소에 넣지 않는다.
- 배포: 미실행. 대표의 배포 승인 대기.
- 범위: GitHub Pages 프로토타입만 수정. 별도 ERP 코드는 이번 변경에 포함하지 않음.
- 추가 관찰: 상자 이동 애니메이션 중 즉시 출력하면 캡처 범위가 어긋날 수 있다. 이번 PDF는 이동이 끝난 뒤 출력했다. 별도 수리 미실행.

`ego-browser nodejs < /절대경로/tests/layout-overlap.mjs`를 실행한다.
